## Banner

A **Banner** is a coloured box for an aside readers shouldn't miss: a correction, an update, a disclosure.

1. Insert **Banner** (type `/banner`).
2. Pick a **Style**: _Info_, _Warning_, _Error_ or _Success_. Each has its own colour.
3. Write the note. It can have bold, italic, underline and links.

Keep it to a sentence or two. For a correction, say what changed and when.

## Code

The **Code** block shows code in a fixed-width box with syntax colouring, so it isn't reflowed like prose.

1. Insert **Code** (type `/code`).
2. Choose the **Language**: TypeScript, JavaScript or CSS.
3. Paste the code.

For a word or two of code inside a sentence, there's no need for a block.
