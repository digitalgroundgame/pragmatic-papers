When one picture isn't enough, the **Media Collage** block shows a set of them together. It's in the block menu of the article editor.

## Setting it up

1. Insert **Media Collage**.
2. Pick a **Layout**: _Grid_ or _Carousel_.
3. Under **Images**, add a row for each picture or video and choose it from Media. Drag rows to change the order.

## Grid or carousel

- **Grid** shows them two to a row (one per row on phones). An odd one out is centred on the last row. Captions are hidden in the grid.
- **Carousel** shows one at a time with previous and next arrows, and readers can swipe on phones. It loops back to the start, and each image's caption shows under it.

In both, clicking an image opens it full size.

## Good to know

- Captions and alt text come from each item in Media, so set them there.
- An image used in a collage on a published article can't be deleted from Media until it's taken out (see [Why some media can't be deleted](/docs/media-references)).
