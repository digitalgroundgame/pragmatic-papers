The **Timeline** block lays out events along a vertical line, alternating left and right. It's in the block menu of articles and pages.

## Adding events

Give the timeline an optional title, then add one row per event:

- **Date** (required). Readers see it as, for example, _November 4, 2021_.
- **Title** and **Description**.
- **Avatar**: a picture from Media, shown as a small circle beside the event.
- **Enable citation**: tick it to add a source link.

Events appear in the order you enter them, not sorted by date, so add them in the order you want them read. Drag rows to reorder them.

A picture used by a timeline on a published article is protected from deletion in Media (see [Why some media can't be deleted](/docs/media-references)).
