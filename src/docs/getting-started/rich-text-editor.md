Articles, volumes' editor's notes and these help docs are all written in the same editor. Everything you add is either text, which you format, or a **block**: a photo, a map, a timeline, a quote card and so on.

## Formatting text

- **Select some text** and a small toolbar appears above it: bold, italic, underline and link (articles add strikethrough, subscript and superscript).
- The **toolbar at the top** of the editor does the same, plus headings, lists, alignment and indentation.
- **Shortcuts** work as you type at the start of a line: `##` makes a heading, `-` a bulleted list, `1.` a numbered list and `---` a dividing line. In articles, `>` makes a quote. Ctrl or Cmd with B, I or U does bold, italic or underline.

Use headings in order: **Heading 2** for sections, **Heading 3** inside them. They become the article's outline for readers and search engines.

## Links

Select the text and click the link button. Choose **Custom URL** for another site, or **Internal link** to pick one of our articles, volumes or pages: an internal link keeps working if its slug changes.

## Adding a block

There are two ways in:

1. Type `/` on an empty line. A menu opens with every block and format; keep typing to filter it (`/time` finds **Timeline**) and press Enter.
2. Hover to the left of a line and click the **+** that appears.

The block opens as a small form inside the text. Fill it in; it saves with the rest of the page. Collapse it with the arrow on its title bar to get it out of the way, or remove it from its menu.

A few blocks are **inline**, so they sit inside a sentence: footnotes and inline math. Type `/` mid-sentence to find them, or see [Add footnotes as you type](/docs/footnotes).

## Moving things

Hover to the left of any paragraph or block and drag the handle (⋮⋮) up or down to move it.

## Which blocks where

- **Articles** have the most: Banner, Code, Interactive Map, Media, Media Collage, Display Math, Squiggle Rule, Social Embed and Timeline, plus footnotes and inline math.
- **Help docs** keep it simple: Banner, Code, Media and Media Collage.

## Writing a help doc

Editors can write docs under **Help → Docs**. Give it a title, a one or two sentence **Summary** (that's what the bell shows), and the date it should be listed under in **Published At**. Leave **Audience** empty for everyone, or pick the roles it's for. Ask a developer to add it to the next release so it ships to every site.
