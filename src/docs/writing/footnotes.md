The quickest way to add a footnote is to type it where it belongs: `[^` then the note, then `]`. When you type the closing bracket it becomes a footnote.

- Typing `[^` also opens a list of notes you've already written in this article. Pick one to cite the same source again.
- To add a source link, open the footnote and tick **Enable Attribution**, then paste the **Attribution Link**. It opens in a new tab for readers.
- Footnotes are numbered for you when you save, in the order they appear.
- A reused footnote is read-only. To change it, delete it and add it again.

Readers see a small numbered link in the text. The notes are listed under **Sources** at the end of the article.
