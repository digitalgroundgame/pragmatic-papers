The bell in the top right of the admin, beside your avatar, is where new features are announced. Each one comes with a help doc, like this one, which reaches the bell once an editor publishes it.

## Reading it

- **The number on the bell** counts what you haven't read.
- **Click the bell** to see the list, newest first. Each item has a picture, a title, a sentence about the feature and the day it arrived. A dot marks the ones you haven't opened.
- **Click an item** to open its doc in a new tab. It counts as read.
- **Mark all as read** clears the dot from everything.
- **See all** opens [What's new](/docs/whats-new), every doc, newest first.

You're only told about features that matter to your role. A doc for editors doesn't reach writers, for example, but every doc is still on /docs for anyone who wants it. Docs dated before your account was made don't count as unread.

## Turning it down

Click the gear in the bell's menu to choose what it tells you about. Untick **Docs** and new docs stop counting on the bell. You can still open the list and the docs whenever you like.

What you've read and what you've turned off are saved to your account, so they follow you to another computer.

## Publishing a release's docs

Editors: a release that ships a help doc adds it under **Help → Docs** as a draft, and nobody is told until it's published. After a release, look there for drafts, read each one, change what you like, and publish it. The bell announces it then. The doc is yours from then on: a release never publishes, overwrites or deletes it, and one you delete stays deleted.

When a release changes a doc you already have, it saves the new copy as a draft on top of yours, and what readers see stays as it is. The doc shows as **Changed**: open its **Versions** tab to compare the suggestion with what's published, then publish it, edit it first, or discard it with **Revert to published**. A suggestion you discard isn't offered again. If you're partway through a draft of your own, the release leaves it alone, and a later one offers the change once you've published or discarded your draft.
