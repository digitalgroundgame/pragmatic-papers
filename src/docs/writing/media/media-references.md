Deleting an image that a published article still shows would leave a hole on the live site. So a media item that published content uses can't be deleted until nothing published uses it any more.

## Where it's used

Open the media item and switch to the **References** tab, next to **Content**. It lists every published document that uses the item, with the field it's in: for example an article's hero image, its narration audio, its SEO image, or a block in its content. Click a title to open that document in a new tab.

If nothing published uses it, the tab says so and you can delete it as usual.

## What counts

- **Only published versions count.** A draft that points at the item doesn't stop you deleting it, so check your own drafts before you do.
- Articles, pages, volumes, topics, interactives, help docs and user profile pictures are all checked.
- Inside content, a **Media Block**, an image in a **Media Collage** and a **Timeline** event's picture count. A plain link to the file doesn't.

## Deleting

If you try to delete an item that's in use, the admin refuses and names up to three of the documents using it, for example: _Can't delete: it's used in "The Article" (article hero image). Replace or remove it there first._ This applies to bulk deletes from the Media list too.

Editors and above can delete any media; everyone else can delete only what they uploaded.

## Detaching

You can replace or remove the item in each document yourself, or let the References tab do it:

1. Click **Detach** beside a document.
2. Confirm with **Detach and publish**.

Detaching takes the item out of that field and publishes the document straight away. A Media Block showing it is removed, a collage loses that one image (and goes entirely if it was the last one), and a timeline event loses its picture.

## If detaching doesn't work

- **The document has unpublished changes.** Detaching would publish them too, so publish or discard them first.
- **You don't have permission.** Detaching publishes, so it needs someone who can publish that document. Writers can ask an editor.
- **Saving put the media back.** Some fields fill themselves in from another one (an article's SEO image comes from its hero image). Detach the other field first.
